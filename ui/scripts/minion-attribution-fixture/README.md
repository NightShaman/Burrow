# Minion attribution acceptance

Build with `node scripts/minion-attribution-fixture/build.mjs`, then run
`python3 scripts/minion-attribution-fixture/serve.py` and open its printed port.
Uses the actual activity projection and transcript with local synthetic data;
no backend mutation, model execution, or API access (connect-src none).

At desktop width, check Hatchet and Smatchet in Pending, Live, and Saved states:
parent portrait/name on instructions, no duplicate on persistence, child reply
identity unchanged, and Goblin King identity only on the actual operator followup.
Check header alignment, readable message density, controls, and no horizontal overflow.
