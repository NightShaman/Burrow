Follow the [first-run wizard](../guide/first-agent.md#complete-the-first-run-wizard). For an uncertain submission or an older profile error, read [setup completion and recovery](../guide/first-agent.md#setup-completion-and-recovery) before retrying or clearing browser storage.

Use [API-key setup](../guide/first-agent.md#api-key-or-compatible-endpoint) or [OAuth after setup](../guide/first-agent.md#oauth-after-setup); these are separate authentication choices. Keep credentials and callback codes private.

## Set operating preferences

Review [operating preferences](../guide/first-agent.md#set-operating-preferences), including timezone, tool grants, retention, and background provider use.

## Configure OIDC before remote access

Follow [OIDC before remote access](../guide/first-agent.md#configure-oidc-before-remote-access) and the detailed [authentication reference](../security/authentication.md). Keep setup local until access controls are configured.

## Verify one conversation

[Send the first message](../guide/first-agent.md#send-the-first-message), then reload and check the persisted result. Health or HTTP success alone is not a successful model conversation.
